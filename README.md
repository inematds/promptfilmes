# 🎬 Prompt Director — Imagens e Cinema com IA

Curso completo de prompts visuais para geradores de imagem e vídeo: Midjourney, Sora, Veo, Runway, Flux, Seedance, Kling, Nano Banana, Ideogram e mais.

**Site:** https://inematds.github.io/promptfilmes/

- **🔵 Trilha 2 — Técnicas** · Em breve
- **🟣 Trilha 3 — Avançado** · Em breve
- **🟡 Trilha 4 — Receitas Prontas** · Em breve

## Como rodar localmente

Não tem build. Abrir qualquer `.html` direto no navegador.

```bash
python3 -m http.server 8000
# acessar http://localhost:8000
```
