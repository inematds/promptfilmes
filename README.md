# 🎬 Prompt Director — Imagens e Cinema com IA

Curso completo de prompts visuais para geradores de imagem e vídeo: Midjourney v7, Sora 2, Veo 3, Runway Gen-4, Flux 1.1 Pro, Flux Kontext, Nano Banana, Seedance 2, Kling 2.5, Ideogram 3 e mais.

**Site:** https://inematds.github.io/promptfilmes/

## Estrutura

- **🟢 Trilha 1 — Fundamentos** (5 módulos) · A gramática do prompt visual
- **🔵 Trilha 2 — Técnicas** (5 módulos) · Sintaxe e controle de cada ferramenta
- **🟣 Trilha 3 — Avançado** (5 módulos) · Direção de arte, storytelling, pipeline híbrido
- **🟡 Trilha 4 — Receitas Prontas** (4 módulos × 6 receitas) · Biblioteca copy-paste

**Total:** 1 landing + 4 índices + 19 módulos = 24 páginas

## Como rodar localmente

Não tem build. Abrir qualquer `.html` direto no navegador.

```bash
python3 -m http.server 8000
# acessar http://localhost:8000
```
